# 计算器界面规格（MVP 取向）

## 目标

先做一个本地可跑的**手动伤害计算器**：搜索选择宝可梦与招式，少量默认值即可出伤害区间。
截图识别 / 悬浮窗读取队伍是后期功能，本轮不做。

## 排布

- **桌面端**：左右两栏（左攻击方，右防御方），顶部对战条件。
- **手机端**：上下堆叠——攻击方卡片在上，防御方卡片在下，对战条件折叠到顶部或底部；
  不做左右双栏（手机宽度不够）。
- 支持「攻守互换」按钮，快速对调双方。

## 默认少填原则

打开页面只要求选：攻击方宝可梦 + 招式、防御方宝可梦。其余给中性默认值，用户需要再展开：

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 性格 | 中性 ×1.0 | 攻击/防御侧各三态 ×0.9 / ×1.0 / ×1.1 |
| 能力点数 | 0 | 单项 0–32，六维合计 ≤66；滑块或步进 |
| 能力等级 | 0 | ±6，± 按钮 |
| 天气 / 场地 | 无 | 顶部条件区 |
| 特性 / 道具 | 未启用 | 选了宝可梦后给候选，可关发动 |
| 状态 | 无 | 烧伤（物理 ×0.5）、帮助（×1.5）、反射壁/光墙、友谊防守 |

## 攻击方卡片字段（对照参考图）

- 宝可梦搜索框（按中文名 / 英文 / 别名匹配，内部存 canonicalId/showdownId）
- 形态选择（Base / Mega / 地区形态等，同种族多形态时出现）
- 种族值条与当前能力值（选完性格+点数后实时显示）
- 招式搜索框：**只列该宝可梦当前形态可学招式**；条目带属性、物理/特殊、威力、命中
- 性格修正三态；攻击能力点数滑块；能力等级 ±
- 状态：烧伤、帮助
- 特性候选（标注使用率/默认特性）、是否发动
- 持有物搜索；同伴特性（无 / 力量点 / 蓄电池 / 钢之意志 / 正电 / 负电，双打）

## 防御方卡片字段

- 宝可梦搜索框 + 形态
- HP / 特防（或物防）能力值实时显示
- 性格修正；HP 点数、对应防御点数滑块；能力等级 ±
- 特性候选；持有物
- 状态：反射壁/光墙、友谊防守

## 对战条件区（顶部）

- 单打 / 双打；单体 / 多体（范围招 ×0.75）
- 天气：无 / 晴 / 雨 / 沙 / 雪
- 场地：无 / 电气 / 青草 / 精神 / 薄雾
- 重力：无 / 有（留接口）

## 结果区

- 每个招式：伤害 min~max、占对方 HP 百分比区间、16 档、OHKO/2HKO 概率或次数
- 标签：本系一致 ×1.5、属性相性 ×2 / 免疫、烧伤、墙等关键前提
- 变化招式显示「无直接伤害」
- （后期）多招并列、对方多配置模板包络、假想敌添加

## 数据流

界面输入 → 内部 `KnownPokemonBuild` / `BattleCondition`（参照 `reference/.../src/damage/types.ts` 契约）
→ 计算内核 `src/damage.py` → 结果 `DamageRange` + KO 摘要 → 中文显示。
中文名 ↔ 内部 ID 走 `data/ref/v18/zh-Hans.json` 映射。
